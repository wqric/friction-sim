# PhysLab — Интерактивная платформа обучения физике

Модульная веб-платформа физических лабораторий и задач по механике на стеке **FastAPI + Vue 3**. Дизайн спроектирован по принципам инженерного минимализма (Unslop) — чистые координатные сетки, векторные диаграммы сил, точные численные расчёты и интерактивные графики.

## Доступные лаборатории:
1. **Динамика: Сила трения на наклонной плоскости** — переход от трения покоя $mg\sin\alpha$ к скольжению $\mu mg\cos\alpha$, критический угол $\alpha_{\text{кр}} = \arctan\mu$, перетаскивание маркёра на графике $F_{\text{тр}}(\alpha)$.
2. **Кинематика: Баллистика** — полёт тела под углом к горизонту, расчёт дальности $L$, максимальной высоты $H$, времени полёта и анимация вектора мгновенной скорости.
3. **Колебания: Гармонические маятники** — математический ($T = 2\pi\sqrt{l/g}$) и пружинный ($T = 2\pi\sqrt{m/k}$) маятники, перекачка кинетической и потенциальной энергий в реальном времени.
4. **Законы сохранения: Соударения тел** — одномерный центральный упругий и абсолютно неупругий удары двух тележек с сохранением импульса и расчётом рассеяния механической энергии.

## Интерактивные задачи:
К каждой лаборатории подключён банк расчётных задач с мгновенной автопроверкой численного ответа через REST API FastAPI с учётом допустимой погрешности.

## Локальный запуск:
```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск сервера
python run.py
# Или напрямую через uvicorn:
# uvicorn backend.app.main:app --host 0.0.0.0 --port 8000
```
После запуска откройте в браузере: `http://localhost:8000`.

## Развёртывание на сервере (CI/CD):
Проект автоматически развёртывается на production-сервер при каждом `git push` в ветку `main` с помощью GitHub Actions.
